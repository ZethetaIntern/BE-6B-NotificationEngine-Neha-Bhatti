# 🔔 Notification Engine API ✨

Welcome to the **Notification Engine** project! 🚀 This is a scalable backend service built to handle and process user notifications asynchronously using Node.js, Express, PostgreSQL, and TypeScript.

---

## 🌟 Features

- 📩 **Notification Queuing:** Seamlessly queue notifications for delivery.
- ⚙️ **User Preferences:** Dynamic channel filtering (Email, SMS, Push, WhatsApp).
- 🗄️ **PostgreSQL Integration:** Robust data storage for notifications and user settings.
- 🛠️ **Type Safety:** Built with TypeScript for reliable and maintainable code.

---

## 🛠️ Tech Stack

- **Language:** TypeScript 💙
- **Runtime:** Node.js 🟢
- **Framework:** Express.js 🚂
- **Database:** PostgreSQL 🐘
- **Testing Tool:** Postman 🚀

---

## 🚀 Getting Started

### 1. Prerequisites 📋

- Node.js (v18+) 🟢
- Docker Desktop (for PostgreSQL) 🐳
