# 🔔 Notification Engine API

A TypeScript + Node.js backend service for creating and managing notifications with PostgreSQL persistence.

## Features

- Notification creation API
- PostgreSQL persistence
- User notification preferences schema
- Notification status tracking
- UUID-based notification IDs
- JSON notification payloads
- Docker-based infrastructure
- TypeScript type safety

> Kafka, RabbitMQ, Redis and channel delivery workers are infrastructure dependencies in the current project. They should not be considered fully integrated until their application-level producers/consumers/workers are implemented and tested.

## Tech Stack

- TypeScript
- Node.js
- Express.js
- PostgreSQL
- Docker / Docker Compose
- Kafka
- RabbitMQ
- Redis

## Prerequisites

- Node.js 18+
- npm
- Docker Desktop
- Git
